# Wii Menu Website

This project is a personal website inspired by the iconic Nintendo Wii Menu interface.

The goal was to recreate the look and feel of the original Wii home screen while adapting it into a modern, responsive webpage that serves as a personal hub for my online profiles.

## Features

- Wii Menu-inspired interface.
- Responsive design for desktop and mobile devices.
- Interactive cards with hover animations.
- Direct access to my personal profiles.
- Custom backgrounds for desktop and mobile.
- Optimized images for different screen sizes.

## Technologies

- HTML5
- CSS3
- JavaScript

## Preview

The project recreates the clean and minimal aesthetic of the Nintendo Wii Menu while providing quick access to my online platforms.
